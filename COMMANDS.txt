XivUI COMMANDS
==============
Addon commands: //xivui | //xui | //htb
Each component has one command word (listed below). The hotbar also uses //htb.

-------------------------------------------------------------------------------
GLOBAL
-------------------------------------------------------------------------------
//xui                        Print the addon version and a command summary
//xui enable <component>     Enable a component
//xui disable <component>    Disable a component
  Components: status, exp, target, party, aggro, dps, hotbar, request, notify,
              cast, loot, weak, menu
  Example:  //xui disable dps
  Example:  //xui enable target
  Note:     OFF by default: cast (castbar), dps, weak (enemy weakness), loot (enemy
            drops). Enable any with `//xui enable <name>`.

//xui menu                     Open the XivUI Menu, the easiest place to configure
                               everything (components, theme, hotbars, HUD layout).
//xui theme <ffxi|ffxiv>       Switch the overall UI theme (default: ffxiv). Reloads.

Scroll Lock / F12              Toggle all UI visibility (also hides FFXIDB minimap if loaded)

-------------------------------------------------------------------------------
HUD LAYOUT EDITOR  (the main way to move and scale every component)
-------------------------------------------------------------------------------
Open the XivUI Menu (//xui menu) and use the HUD Layout editor to drag any
component into place and scroll wheel to scale it.Exact positioning is still available 
per component via `pos <x> <y>`, and most components can also use `scale <factor>` from chat.

TIP: every command works with //xivui or the shorter //xui (the hotbar also uses //htb).
     Each component is addressed by one word: the Prefix shown in its section below.
     Anything in <angle brackets> is a value you supply; [square brackets] are optional.

-------------------------------------------------------------------------------
ENEMYWEAK  (target weakness icons: the magnifying glass by the enemy's name)
Prefix: //xui weak
-------------------------------------------------------------------------------
How it works: a small magnifying glass icon is to the right of an enemy target's
              name on the target HP bar. Click it to expand that enemy's weakness
              icons in place (weakest element first; absorbed/immune shown dimmed);
              click again to collapse. Hovering an icon names the weakness. Sizes
              and offset scale with the target bar (//xui target scale).

always [on|off]                Always show the weakness icons expanded.
off <dx> <dy>                  Nudge the glass / icon position
  Example:  //xui weak always on
  Example:  //xui weak off 2 -1

-------------------------------------------------------------------------------
ENEMYLOOT  (target drop list: the loot bag under the enemy's HP bar)
Prefix: //xui loot
-------------------------------------------------------------------------------
How it works: a small bag icon is placed below an enemy target's HP bar. Click it to
              open that enemy's possible drops, grouped into collapsible categories
              (drops / steal / despoil / etc) with % chances where
              known. Click a category header to collapse/expand it; scroll the
              panel to see more. The bag + panel scale with the target bar, plus
              the loot scale below. Drops/steals/despoils you actually see are
              learned and fill any gaps in the wiki data.

pos <x> <y>                    Set an exact bag position
off <dx> <dy>                  Nudge the bag relative to the HP bar's end
scale <0.5-2.5>                Extra bag/panel scale
learned                        Print how many loot entries have been learned
forget                         Clear the learned loot cache
  Example:  //xui loot off 0 2
  Example:  //xui loot scale 1.2
  Example:  //xui loot learned

-- HOTBAR SETUP --
New characters start with EMPTY hotbars. The easiest wayto set them up is 
the XivUI Menu (//xui menu): the AUTOGEN tab fills bars from your
learned actions per job, and the ACTIONS / MACROS / CHOICE tabs let you drag actions
onto slots. The chat commands below do the same thing and are optional/advanced.

-- HOTBAR SETUP (gen mode) --
set gen mode                   Enable autogen (gen) mode
setbar <category> <1-6> [b|g]  Assign a spell/ability category to a hotbar row
  Categories: main, sub, ws, healing magic, enhancing magic, enfeebling magic,
              dark magic, elemental magic, blue magic, ninjutsu, songs,
              summoning, geomancy, trust
unsetbar <category>            Remove a category assignment from its hotbar row
setbar general list            Print the current xivhotbar_general_list entries
autogen  (generate)            Populate all assigned hotbar rows for current job/level
updategen                      Same as autogen but preserves manual overrides
  Example:  //htb set gen mode
  Example:  //htb setbar healing magic 3
  Example:  //htb setbar ws 1 b
  Example:  //htb autogen
  Example:  //htb updategen

-- HOTBAR SETUP (manual mode) --
set manual mode                Enable manual mode (no autogen)
set slot <row> <slot> <type> <action> [target] [alias]
  Place an action on a specific slot.
  Types:    ma (magic), ws, ja, ct (corsair roll), item, macro
  Targets:  me, stpc, stnpc, bt, st, t (default: me)
  (Icons come from data/action_icons.lua automatically; to use a custom icon for one
   slot, edit its 6th field in the job .lua - see EDITING THE LUA below.)
  Example:  //htb set slot 1 1 ma Cure stpc
  Example:  //htb set slot 1 2 ws Savage Blade bt
  Example:  //htb set slot 1 3 ja Provoke bt Prov
  Example:  //htb set slot 1 4 item Hi-Potion me
  Example:  //htb set slot 1 5 ct Chaos Roll me

-- EDITING THE LUA DIRECTLY (off-game) --
  Per-character files live in:
    components/xivhotbar3/data/<YourName>/<job>.lua    (main + sub-job slots)
    components/xivhotbar3/data/<YourName>/General.lua  (cross-job slots)
  Each slot is one table line:
    { '<env> <row> <slot>', '<type>', '<action>', '<target>', '<alias>', '<icon>' }
      env    = battle | field
      type   = ma | ws | ja | ct | item | macro | choice
      action = spell/ability/item name, a macro command, or a choice group id
      target = me | stpc | stnpc | bt | st | t
      alias  = short label drawn on the slot
      icon   = optional, path under images/icons/ (e.g. ffxiv/whm/cure); '' = default
  Example (normal):  { 'battle 1 1', 'ja', 'Provoke', 'bt', 'Prov', 'ffxiv/war/provoke' }
  Example (macro):   { 'battle 1 5', 'macro', '/ma "Cure" <me>', 'me', 'Cure', '' }
  Run //htb reload after editing to apply the changes.

-- CHOICE SLOTS (one slot that pops up a group of actions) --
  A choice slot is just a slot whose type is "choice" and whose action is a choice
  group id.  //htb choice list  prints the available ids (e.g. dnc_sambas, sch_stratagems).
  Make one:
    - In gen mode, autogen builds them for you (tiered spells, weaponskills, ...).
    - //htb collapse weaponskills <row> <slot> [weapon]   (turns a slot into a WS choice)
    - Or add it to the job .lua:
        { 'battle 2 1', 'choice', 'dnc_sambas', '', 'Samba', 'ffxiv/dnc/pirouette' }
  Unmake one:
    - //htb resetslot <row> <slot>   (or just assign a normal action over the top of it)
  Custom group (advanced): add an entry to choice_groups.groups in
    components/xivhotbar3/lib/choice_groups.lua, matching the existing format.

-- ICONS --
  The FFXIV style icon for each action is mapped in
  components/xivhotbar3/data/action_icons.lua (keyed by "type|name", e.g. "ja|provoke"),
  with the images under components/xivhotbar3/images/icons/. Autogen assigns them
  automatically. To change one everywhere, edit action_icons.lua; to change a single
  slot, set its 6th .lua field (see EDITING THE LUA). Unmapped actions fall back to a
  generic icon.

-- SLOT MANAGEMENT --
resetbar [<row#> | <env> <row#> | all [<env>]]  Clear a hotbar row or all rows
resetslot [<row#> <slot#> | <env> <row#> <slot#>]  Clear a single slot
resetall [<env>]               Clear all rows (optionally for one environment only)
collapse weaponskills <row#> <slot#> [b|g] [weapon]
                               Collapse all WS for a weapon type into one choice slot
execute <hotbar#> <slot#>      Trigger a slot programmatically

-- HOTBAR SETS (saveable per-job loadouts) --
set visible                    Toggle the 3x3 set grid (nodes 1-9). Drag it in //htb move.
                               If it would be offscreen it is recentered automatically.
set save <1-9> ["name"]        Snapshot the current job's hotbar into a node: slot contents
                               plus the layout (bar count, bar positions, custom slot
                               offsets, hidden rows, scale). The optional name is shown in
                               //htb set list (reuses the old name, or "Set N", if omitted).
                               A saved node is seafoam green; empty nodes are grey.
set load <1-9>                 Load a saved set for the current job (or click a green node).
                               Reloads the addon so the saved layout reapplies.
set clear <1-9>                Delete the set saved in a node
set list                       List saved sets and names for the current job
set pos <x> <y>                Move the grid to exact coordinates (no args = print current)
  Example:  //htb set visible
  Example:  //htb set save 1 "Tank set"
  Example:  //htb set load 1

DPS  (real-time alliance DPS / damage parser, ACT style overlay)
Prefix: //xui dps
-------------------------------------------------------------------------------
-- GENERAL --
(no args)                      Print the command summary in chat
visible                        Toggle the overlay on/off (starts hidden by default)
move / reposition              use the HUD Layout editor (see HUD LAYOUT above)
reset                          Clear the current parse (start a fresh encounter)
pos <x> <y>                    Move the overlay to exact coordinates
scale <0.5-2.5>                Set the DPS panel scale
roles                          Show the role color legend and any manual overrides

-- SETTINGS:  set <flag> <value> --
set numplayers <n>             Max number of rows shown (default: 12)
set background <true|false>    Draw the dark backdrop panel behind the rows (default: false)
set autoresetdelay <s>         Seconds of no combat before the parse auto-resets (default: 9)
set autoreset <true|false>     Auto-clear the parse once the encounter ends (default: true)
set trackhealing <true|false>  Track cure/heal amounts -> HPS column (default: true)
set trackmagicburst <true|false>  Track magic burst damage (default: true)
set separatesc <true|false>    false = one shared "Skillchain" row (sum of all sc closers);
                               true  = credit skillchain damage to the closer's own row
set separatemb <true|false>    false = one shared "Magic Burst" row (sum of all mb casters);
                               true  = credit magic burst damage to the caster's own row
set combinepets <true|false>   true  = fold pet damage into the owner's own row;
                               false = each pet gets its own "Owner: Petname" row
                               (default: false)

-- ROLE COLORS:  set <slot> <role> --
set <slot> <role>              Force the role color for whoever is in a party/alliance slot.
                               Slots: 1-6 = your party, 7-18 = alliance. Persists per name.
                               Roles: tank, healer, support, dps, pet, other
                               (use "auto" to clear the override and color by job)
  Example:  //xui dps set 2 healer
  Example:  //xui dps set 3 auto
  Role colors: tank=blue  healer=green  support=lavender  dps=red
               pet=pale brown   Skillchain/Magic Burst=gold   unknown=gray

-- ENEMY FILTER (limit the parse to specific mobs) --
filter add <name> [name ...]   Only count damage against mobs matching these name patterns
filter clear                   Remove all filters (count every mob again)
filter show                    List the active mob filters

NOTIFICATION  (loot toasts)
Prefix: //xui notify
-------------------------------------------------------------------------------
move / reposition / setup      use the HUD Layout editor (see HUD LAYOUT above).
                               The loot toast and the party join popup are separate boxes.
pos <x> <y>                    Set exact start position (where each toast begins)
pos join <x> <y>               Set exact position of the party join popup
scale <0.5-2.5>                Scale the loot toast text
scale join <0.5-2.5>           Scale the party join popup
party [on|off]                 Also show what party members obtain (default: off = your
                               loot only).
test                           Queue a sample loot toast
clear                          Drop the queue and the current toast
  Notes: shows one loot item at a time.
         By default only your loot shows; `party on` adds party members' drops.
         Detection uses whichever fires first — the inventory packet (0x020, your loot),
         the treasure-pool packet (0x0D2, supplies the item id), or the chat line
         ("You obtain ...", "You find ... on ...", "<member> obtains ...") as a fallback and is
         deduped so each drop shows once.
  Example:  //xui notify move
  Example:  //xui notify party on
  Example:  //xui notify pos 20 300

CASTBAR  (spell cast bar + auto-attack swing timer)   [OFF by default]
Prefix: //xui cast
-------------------------------------------------------------------------------
Enable first:  //xui enable castbar
move / reposition              use the HUD Layout editor (see HUD LAYOUT above).
                               The cast bar and the auto-attack bar are separate boxes.
pos <cast|swing|ranged> <x> <y>  Set an exact position for one bar
scale <cast|swing|ranged|both> <f>  Set scale factor (0.4–3.0), e.g. 1.5
cast [on|off]                  Show/hide the cast bar
swing [on|off]                 Show/hide the melee auto-attack swing bar
ranged [on|off]                Show/hide the cyan ranged-attack bar (its own timing; only
                               appears while you actually shoot). Sits above the swing bar.
swingtext [on|off]             Show/hide the xN + interval labels on the swing/ranged bars
                               (off by default)
test                           Show a 6-second animated preview of both bars
reset                          Recenter both bars and reset scale
  Notes: The pink CAST bar is hidden until you cast a spell with
         a cast time, then shows the spell name + remaining seconds; an interrupt flashes it
         red and blinks before it disappears. The smaller yellow SWING bar is placed above it,
         right aligned to the same end, and fills toward your next melee swing while in combat.
		 Swing timing is measured from the interval between attack rounds 
		 (approximate).
  Example:  //xui enable castbar
  Example:  //xui cast scale both 1.4
  Example:  //xui cast swing off
